# Gig Demo Projects

Three portfolio-ready static demos for selling practical web work to small businesses.

## 1. Local Service Website
Folder: `01-local-service-site`

**What it sells:** one-page local business websites for mechanics, handymen, cleaners, landscapers, etc.

**Pitch:** “I build simple, mobile-friendly websites that make it easy for customers to understand what you do, trust you, and request a quote.”

## 2. Shopify/Product Page Cleanup
Folder: `02-shopify-product-cleanup`

**What it sells:** ecommerce product-page cleanup, buyer-flow repair, trust fixes, and mobile conversion improvements.

**Pitch:** “I clean up confusing product pages so customers can quickly understand the offer, see the real price, trust the store, and buy without feeling scammed.”

## 3. Map/Control-Panel Dashboard
Folder: `03-ops-map-dashboard`

**What it sells:** small internal web tools, dashboards, upload tools, mapping interfaces, route/field-work panels, and admin pages.

**Pitch:** “I build practical dashboards and control panels that help small teams track field work, stops, jobs, locations, notes, and status in one place.”

## How to use
Open each folder's `index.html` file in a browser.

These are static demos. They do not require a server, database, package install, or build step.

## Suggested portfolio wording

> I build practical websites and lightweight web tools for small businesses: mobile-friendly pages, dashboards, forms, upload flows, maps, ecommerce cleanup, and simple internal tools. My focus is clarity, usability, and getting rid of confusing layouts that cost customers time and trust.
